# The `graft-m3f` test install

A shared test install for merge-p99 ([thread](https://ampcode.com/threads/T-01a1d2d6-7fda-704c-ab49-d3df659ffdcb)) and rehydrate-batch ([thread](https://ampcode.com/threads/T-01a1d2d6-889e-720b-b84b-3939b1ed7b79)), who share it. It is built the way `install-m3d.md` built `graft-m3d`, with two differences: it is built from main `20147db`, and its shards run on `standard-4` from the first site day (`SHARD_INSTANCE=standard-4`, which the operator approved for test installs on 2026-11-13). `graft-m3e` and `graft-m3f` were built at the same time from one worktree. Nothing here touches another install. Built 2026-11-13 from 03:07Z (branch `install-m3ef`, from `20147db`).
