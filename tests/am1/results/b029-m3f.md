## The queue tail

Split from the leader's trace with `tests/fanout/slotsplit.py` (`tests/fanout/raw/tsave-m3fb29.jsonl.xz`, site 0, the load window). Method:
- Each `/commit` that reached the leader's handler (`Entered`, route code 3) is joined to the first cut at or after it. Every cut ended `Empty`, so a cut takes everything that arrived since the one before.
- Its batch is appended as the (held + 1)-th append after the cut.
- Queue is append minus arrival, split at the last apply as `/stats` does (`queue_split`).
- The trace covers 11,587 commands in the window against `/stats`' 10,521. Its slot and post (p50/p99 217/635 and 3/333) match `/stats`' 222/704 and 3/327 closely, so the per-command split stands for it [measured]. Arrival is the handler's entry, before body read and admission, so queue reads a few ms long [inference].

**By class.** The tail is not one class's. Mixed cuts are counted by each class's share of the cut:
- Human, weight 1,873: queue p99 739, slot p99 648.
- Agent, weight 9,714: queue p99 726, slot p99 628.
- Cuts of only one class: human (n 51) slot p99 361, agent (n 4,743) slot p99 554.
- No MergeQueue or Bot command was cut in the window.
